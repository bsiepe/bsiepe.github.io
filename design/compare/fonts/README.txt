Web fonts for the design comparison page (design/compare/index.html).
woff2 files from the Fontsource npm packages (@fontsource/<family>, 5.3.x),
latin and latin-ext subsets only. All licensed under the SIL Open Font License 1.1;
the license text for each family is in licenses/.

Chosen for the site: Crimson Pro (400, 500, 600) and Atkinson Hyperlegible (400, 400 italic, 700).
The other families are only here so the comparison page can show the alternatives.
